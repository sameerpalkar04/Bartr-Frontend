## ✨ Overview

Bartr explores a more sustainable way to exchange goods by helping people find value in items they no longer use. This repository contains the frontend application, focusing on the user interface and the overall experience of interacting with the platform.

## 🚀 Highlights

- 🛍️ **Marketplace Experience** — Browse and explore items available for exchange.
- 🤝 **Item Trading** — Support the idea of exchanging goods instead of simply discarding them.
- 💻 **Modern Frontend** — Built with React-based technologies and TypeScript.
- 🎨 **User Interface** — Designed to make navigating and interacting with the platform straightforward.

## 🛠️ Tech Stack

- **Language:** HTML, CSS, JS

## ⚙️ Getting Started

```bash
git clone https://github.com/sameerpalkar04/Bartr-Frontend.git
cd Bartr-Frontend
yarn install
yarn dev
```

Open the local URL shown in your terminal to view the application.

> If the project uses a different package manager or start script, follow the commands configured in `package.json`.
